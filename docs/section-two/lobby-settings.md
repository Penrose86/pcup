# 2.2 — Lobby Settings

All official events will use the approved Penrose Cup lobby settings.

The designated Race Manager should verify the required settings before the session begins.

Where an incorrect setting is identified before racing begins, it should be corrected where reasonably possible.

Drivers must not knowingly alter, circumvent or exploit the competition settings.

The official Penrose Cup lobby configuration will be published separately and forms part of these Sporting Regulations.

Where a Wildcard Round changes a normal lobby setting, the announced Wildcard requirement takes precedence for that event.
