# 5.13 — Main Stage Standings & Progression

Main Stage team-placement points earned during Week 3 and Week 4 are combined.

All 15 remaining teams are placed into one overall Main Stage standings table.

After the completion of Week 4, the five highest-ranked teams advance to the Semi-Final.

Where two or more teams finish level on Main Stage points, apply the Penrose Cup Main Stage countback procedure.

The countback order is:

1. Best team race results across the Main Stage, beginning with the greatest number of lobby wins.
2. If still tied, the greatest number of second-place team finishes.
3. Then third-place finishes.
4. Then fourth-place finishes.
5. Then fifth-place finishes where required.
6. If still tied, total normal Penrose Cup driver points scored by the team across Weeks 3 and 4.
7. If still tied, the highest individual driver finishing position achieved during the Main Stage.
