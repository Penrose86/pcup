# 5.4 Penrose Cup Standard Race Points

Race finishing-position points are scaled to the number of race starters. The applicable scale is selected from the total number of drivers who start the race.

| Position | Points | Position | Points |
|---|---:|---|---:|
| P1 | **33** | P11 | **10** |
| P2 | **29** | P12 | **9** |
| P3 | **27** | P13 | **8** |
| P4 | **25** | P14 | **7** |
| P5 | **23** | P15 | **6** |
| P6 | **19** | P16 | **5** |
| P7 | **17** | P17 | **4** |
| P8 | **15** | P18 | **3** |
| P9 | **13** | P19 | **2** |
| P10 | **11** | P20 | **1** |

| Position | Points |

For races with fewer than 12 starters, only positions actually achieved score points. The maximum standard finishing-position score is 33 points for a race victory, before bonus points are added.
