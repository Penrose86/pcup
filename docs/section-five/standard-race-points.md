# 5.8 — Standard Race Points

The standard Penrose Cup points system applies wherever the competition format specifies normal Penrose Cup scoring.

Every classified position from P1 to P20 scores finishing-position points.

| Position | Points |
|---|---:|
| P1 | 33 |
| P2 | 28 |
| P3 | 26 |
| P4 | 23 |
| P5 | 21 |
| P6 | 19 |
| P7 | 17 |
| P8 | 15 |
| P9 | 13 |
| P10 | 11 |
| P11 | 10 |
| P12 | 9 |
| P13 | 8 |
| P14 | 7 |
| P15 | 6 |
| P16 | 5 |
| P17 | 4 |
| P18 | 3 |
| P19 | 2 |
| P20 | 1 |

Every classified finishing position from P1 through P20 is therefore eligible to score points.
